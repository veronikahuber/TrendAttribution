This repository contains all relevant scripts to reproduce the analysis of the study 

Huber, V., et al. <strong>Improvements in life expectancy mask rising trends in heat-related excess mortality attributable to climate change</strong>

<em>Nature Communications</em>, <strong>16</strong>, 11632 (2025) https://doi.org/10.1038/s41467-025-66681-0

Contact: veronika.huber@ebd.csic.es

<b>Content:</b>
<ul>
<li>Files 01a. and 01b. construct the counterfactual temperatures series</li> 
<li>File 02. loads the full data bases</li>
<li>Files 03. to 08. perform the epidemiological analysis and compute attributable mortality</li>
<li>Files 09. to 14. reproduce figures and tables</li>
</ul>
<b>System requirements:</b> All analyses were performed with R version 4.4.1, using the packages <em>dlnm</em> and <em>mixmeta</em>.
