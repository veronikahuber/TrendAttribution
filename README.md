This repository contains all relevant scripts to reproduce the analysis of the study 

Huber, V., et al.: Life expectancy gains mask rising trends in heat-related excess mortality attributable to climate change 

Nature Communications, doi: [to be added]

Contact: veronika.huber@ebd.csic.es

Content:

Files 01a. and 01b. are used to construct the counterfactual temperatures series 
File 02. loads the full data bases
Files 03. to 08. performs the epidemiological analysis and computes attributable mortality
Files 09. to 14. reproduces figures and tables

System requirements:

All analyses were performed with R version 4.4.1 (2024-06-14 ucrt)
